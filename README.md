# 🍽️ Heavenlyte – Restaurant Website

Heavenlyte is a modern restaurant web application developed as part of my **internship project**, where I designed and built my own food brand from scratch.

The project focuses on creating a **clean, responsive, and user-friendly food ordering experience** using **React and Redux**.

## 🔗 Live Demo

👉 https://restaurant-website-nine-dun.vercel.app/

## 📌 Project Overview

- **Project Name:** Heavenlyte  
- **Type:** Internship Project  
- **Domain:** Restaurant / Food Ordering Website  
- **Brand Created:** Heavenlyte  
- **Frontend:** React.js  
- **State Management:** Redux Toolkit  

This project demonstrates my understanding of **real-world React application structure**, **state management**, and **scalable component design**.

## ✨ Features

- Home page with trending and weekly special menus
- Shop page with item listings
- Item details page
- Cart functionality
- Cart synchronization
- Redux-based global state management
- Responsive UI
- Deployed on Vercel

## 🚀 Getting Started

Follow these steps to run the project locally:
### 1️⃣ Clone the repository
```bash
git clone https://github.com/nagaharshitha20/Restaurant-website.git
cd Restaurant-website
```



### 2️⃣ Install dependencies
```bash
npm install
```



### 3️⃣ Start the development server
```bash
npm start
```
### 4️⃣ The application will run on
👉 http://localhost:3000
