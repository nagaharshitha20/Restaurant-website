🍽️ Heavenlyte – Restaurant Website

Heavenlyte is a modern restaurant web application developed as part of my internship project, where I designed and built my own food brand from scratch. The project focuses on creating a clean, responsive, and user-friendly food ordering experience using React and Redux.

📌 Project Overview

Project Name: Heavenlyte

Type: Internship Project

Domain: Restaurant / Food Ordering Website

Brand Created: Heavenlyte

Frontend Framework: React.js

State Management: Redux

This project demonstrates my understanding of component-based architecture, state management, and real-world frontend application structure.

✨ Features

🏠 Home page with trending and weekly special menus

🛍️ Shop page with item listings

📄 Item details page

🛒 Cart functionality

🔄 Cart synchronization

🔐 Authentication service setup

🎯 Redux-based filtering and global state management

📱 Responsive UI

🚀 Getting Started

Follow these steps to run the project locally:

1️⃣ Clone the repository
git clone https://github.com/your-username/Restaurant-website-NagaHarshitha.git

2️⃣ Navigate to the project folder
cd Restaurant-website-NagaHarshitha

3️⃣ Install dependencies
npm install

4️⃣ Start the development server
npm start


The app will run on:

http://localhost:3000
